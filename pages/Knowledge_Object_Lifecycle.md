# Knowledge Object Lifecycle

# Knowledge Object Lifecycle

Every important Wiki page should follow a controlled lifecycle.

## Lifecycle

**Draft** → Review → Verification → Approval → Publication → Periodic Review → Supersession → Archive

## Required Metadata

- owner;
- source;
- version;
- status;
- review date;
- access level;
- related concepts.
