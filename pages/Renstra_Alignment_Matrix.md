# Renstra Alignment Matrix

Future initiatives should be mapped against the existing strategic planning architecture.

## Mapping Fields

- Renstra objective;
- strategic direction;
- programme;
- initiative;
- output;
- outcome;
- KPI;
- responsible institution;
- implementation period.

## Purpose

The matrix prevents the future Blueprint from becoming disconnected from the judiciary's formal planning system.
