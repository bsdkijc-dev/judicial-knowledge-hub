# Judicial Semantic Search

# Judicial Semantic Search

Semantic search retrieves knowledge based on meaning rather than exact keyword matching.

## Requirements

- ontology;
- metadata;
- entity linking;
- relationships;
- source provenance;
- structured claims.

## Strategic Value

Semantic search allows users to discover related judicial knowledge even when different terminology is used.
