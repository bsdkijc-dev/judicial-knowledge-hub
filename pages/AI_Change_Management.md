# AI Change Management

# AI Change Management

AI systems should be reassessed when material changes occur.

## Change Triggers

- model change;
- prompt change;
- retrieval-source change;
- data change;
- vendor change;
- workflow change;
- major system update.

## Required Response

**Change → Reassess → Test → Approve → Monitor**

## Principle

An AI system is not a static asset.
