# Restricted Knowledge Layer

# Restricted Knowledge Layer

Restricted knowledge requires authenticated access and stronger governance.

## Examples

- internal working materials;
- non-public administrative information;
- controlled research;
- draft institutional documents.

## Rule

Technical access controls must match information sensitivity.
