# AI Deployment Gate

# AI Deployment Gate

High-impact judicial AI should pass formal governance gates before deployment.

## Gate Conditions

- defined problem;
- legal authority;
- risk assessment;
- impact assessment;
- security testing;
- data assessment;
- model evaluation;
- human oversight;
- user competency;
- incident procedure;
- audit plan;
- fallback;
- retirement criterion.

## Decision

**Approve / Approve with Conditions / Pilot Only / Reject**
