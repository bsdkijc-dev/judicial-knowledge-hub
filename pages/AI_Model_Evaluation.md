# AI Model Evaluation

# AI Model Evaluation

Judicial AI should be evaluated against the actual tasks for which it will be used.

## Evaluation Dimensions

- accuracy;
- citation integrity;
- reliability;
- limitations;
- robustness;
- security;
- user performance;
- legal-context performance.

## Indonesian Context

Evaluation should include realistic Indonesian legal and administrative scenarios.

## Principle

**Generic benchmark ≠ judicial evidence.**
