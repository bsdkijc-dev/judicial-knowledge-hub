# Judicial Prompt Literacy

# Judicial Prompt Literacy

Judicial Prompt Literacy develops the ability of judges and court personnel to interact responsibly with AI systems.

## Core Skills

- task formulation;
- contextual prompting;
- source requirements;
- verification;
- uncertainty recognition;
- privacy-aware use;
- responsible AI interaction.

## Boundary

Prompt literacy does not transfer judicial authority to AI.
