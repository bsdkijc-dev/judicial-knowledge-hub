# Initiative Card Standard

# Initiative Card Standard

Every strategic initiative should be represented by a standardized Initiative Card.

## Required Fields

- Initiative ID
- Portfolio
- Problem
- Objective
- Owner
- Baseline
- Target
- KPI
- RACI
- Dependencies
- Risk Tier
- Legal Basis
- Cost
- Timeline
- Pilot
- Evaluation
- Scale Decision
- Retirement Criterion

## Decision Logic

**Problem → Intervention → Output → Outcome → Impact**
