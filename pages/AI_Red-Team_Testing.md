# AI Red-Team Testing

# AI Red-Team Testing

Red-team testing deliberately attempts to identify weaknesses before high-impact AI systems are deployed.

## Test Areas

- fabricated citations;
- unsafe outputs;
- prompt manipulation;
- data leakage;
- security weaknesses;
- inappropriate recommendations;
- bias;
- failure under unusual inputs.

## Output

Each identified weakness should be documented, assessed and assigned a remediation owner.
