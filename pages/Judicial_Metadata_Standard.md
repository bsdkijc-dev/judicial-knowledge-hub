# Judicial Metadata Standard

# Judicial Metadata Standard

Metadata makes judicial information discoverable, traceable and interoperable.

## Core Metadata

- identifier;
- title;
- entity type;
- jurisdiction;
- date;
- source;
- version;
- status;
- confidentiality;
- relationships.
