# Five-Level Judicial AI Competency Framework

The framework defines five progressive levels of AI capability.

| Level                                                                                                            | Audience | Core Capability |
|------------------------------------------------------------------------------------------------------------------|----------|-----------------|
| All personnel\|AI fundamentals, risks, privacy, cybersecurity, hallucination awareness, responsible use          |          |                 |
| Judges and staff\|Prompting, summarisation, research assistance, translation, document analysis and verification |          |                 |
| Power users and specialists\|Workflow automation, RAG, knowledge management, data analysis and evaluation        |          |                 |
| Leaders and policy makers\|Procurement, impact assessment, audit, ethics, risk and vendor governance             |          |                 |
| Multidisciplinary specialists\|Law, data, AI, process and ethics architecture                                    |          |                 |
