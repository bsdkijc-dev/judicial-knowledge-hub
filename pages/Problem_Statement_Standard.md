# Problem Statement Standard

# Problem Statement Standard

Every strategic initiative should begin with an explicit problem statement.

## Template

**Current condition → Problem → Affected users → Root causes →** Desired outcome

## Required Questions

1.  What problem exists?
2.  Who experiences it?
3.  What evidence demonstrates the problem?
4.  What is its current baseline?
5.  What happens if no intervention occurs?
6.  What measurable improvement is expected?
