# Judicial Knowledge Graph API

# Judicial Knowledge Graph API

A future API can expose approved knowledge-graph relationships to applications and analytical systems.

## Requirements

- authentication;
- authorization;
- provenance;
- versioning;
- query controls;
- logging;
- rate limiting.

## Boundary

API access does not change the authority of underlying sources.
