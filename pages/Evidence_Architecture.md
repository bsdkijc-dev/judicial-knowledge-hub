# Evidence Architecture

# Evidence Architecture

Evidence Architecture defines how claims in the Judicial Knowledge Wiki are connected to authoritative sources and verified evidence.

## Core Principle

**Claim → Source → Evidence → Verification → Publication**

## Minimum Components

- source registry;
- claim registry;
- provenance;
- evidence level;
- verification status;
- version history;
- reviewer;
- review date.

## Purpose

The architecture prevents the Wiki from becoming an uncontrolled collection of assertions and supports reliable human and machine use.
