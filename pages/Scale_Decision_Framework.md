# Scale Decision Framework

# Scale Decision Framework

A successful pilot should not automatically be scaled.

## Decision Questions

1.  Did the intervention improve the intended outcome?
2.  Was the result measurable?
3.  Were risks acceptable?
4.  Was the solution legally authorised?
5.  Is it interoperable?
6.  Can the judiciary sustain it?
7.  Is workforce capability sufficient?
8.  Is national scaling justified?

## Decision

**Scale / Redesign / Continue Pilot / Stop**
