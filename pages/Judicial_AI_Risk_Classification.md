# Judicial AI Risk Classification

AI use cases are classified according to risk.

| Tier                                                                                             | Example | Control |
|--------------------------------------------------------------------------------------------------|---------|---------|
| Translation or formatting\|Security and quality checks                                           |         |         |
| Administrative classification\|Human review and monitoring                                       |         |         |
| Workload or case-management recommendations\|Impact assessment, audit and strong human oversight |         |         |
| Autonomous judicial decision\|Not permitted as a substitute for judicial authority               |         |         |
