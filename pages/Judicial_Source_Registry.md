# Judicial Source Registry

# Judicial Source Registry

The Judicial Source Registry records authoritative and supporting sources used by the Wiki.

## Source Fields

- source ID;
- title;
- issuing institution;
- date;
- jurisdiction;
- source type;
- official location;
- version;
- validity status;
- access level.

## Source Classes

- legislation;
- regulation;
- judgment;
- official policy;
- institutional document;
- research;
- comparative source.

## Rule

Sources should be distinguishable by authority and evidentiary status.
