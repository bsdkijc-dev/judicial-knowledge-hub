# Initiative Pilot Card

# Initiative Pilot Card

A pilot card defines the controlled experiment before wider deployment.

## Required Fields

- hypothesis;
- pilot site;
- users;
- duration;
- baseline;
- intervention;
- risk controls;
- success criteria;
- evaluator;
- exit criteria.

## Decision

**Scale / Redesign / Continue / Stop**
