# Judicial Statistics APIs

# Judicial Statistics API

A Judicial Statistics API can provide structured access to approved aggregate judicial statistics.

## Requirements

- documented schema;
- versioning;
- authentication where necessary;
- rate limits;
- provenance;
- privacy protection;
- data-quality controls.
