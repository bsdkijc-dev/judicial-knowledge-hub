# Government Institutional Performance Accountability Value

# Government Institutional Performance Accountability Value

Indicator 3.1 measures institutional performance accountability.

## Assessment Components

- performance planning;
- performance measurement;
- performance reporting;
- internal evaluation of performance accountability.

The indicator measures performance for the preceding year (t−1).
