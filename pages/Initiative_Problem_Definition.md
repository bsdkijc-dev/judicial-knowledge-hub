# Initiative Problem Definition

# Initiative Problem Definition

An initiative should address a clearly defined institutional or justice-system problem.

## Required Elements

- current condition;
- affected users;
- evidence;
- root cause;
- consequence;
- urgency.

## Prohibited Logic

**Technology → Find a Problem**

The preferred logic is:

**Problem → Capability → Solution**
