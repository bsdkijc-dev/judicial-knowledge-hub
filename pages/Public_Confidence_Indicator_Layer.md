# Public Confidence Indicator Layer

Strategic Target 2 is measured through four indicators:

1.  [LHKPN Compliance](https://judicialknowledge.miraheze.org/wiki/LHKPN_Compliance)
2.  [Timely Complaint Handling](Timely_Complaint_Handling.md)
3.  [Supervision Recommendation Follow-up](https://judicialknowledge.miraheze.org/wiki/Supervision_Recommendation_Follow-up)
4.  [Court User Satisfaction](https://judicialknowledge.miraheze.org/wiki/Court_User_Satisfaction)

## Knowledge Model

**Integrity + Oversight + Service Quality → Public Confidence**
