# Case Duration Analytics

# Case Duration Analytics

Case Duration Analytics is proposed to identify patterns in case processing time.

## Uses

- identify bottlenecks;
- compare workload patterns;
- support administrative improvement;
- identify areas requiring further investigation.

## Principle

Analytics should improve institutional performance without turning performance indicators into automated judicial decision rules.
