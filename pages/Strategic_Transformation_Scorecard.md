# Strategic Transformation Scorecard

Transformation progress should be assessed across multiple dimensions rather than through technology deployment alone.

| Dimension                              | Question |
|----------------------------------------|----------|
| Did justice improve?                   |          |
| Did accessibility improve?             |          |
| Did unnecessary delay decrease?        |          |
| Did quality improve?                   |          |
| Did institutional integrity improve?   |          |
| Did users experience improvement?      |          |
| Did workforce capability increase?     |          |
| Did institutional resilience increase? |          |
