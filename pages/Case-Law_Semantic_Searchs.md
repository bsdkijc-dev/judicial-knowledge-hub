# Case-Law Semantic Search

Semantic search should allow researchers to find judicial knowledge based on concepts and relationships rather than exact keywords alone.

## Requirements

- source grounding;
- citation;
- relevance ranking;
- temporal validity;
- version awareness;
- human verification.
