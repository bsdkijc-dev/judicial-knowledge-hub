# Datas Literacy for Judges

# Data Literacy for Judges

Data literacy enables judges to understand the strengths and limitations of data and analytical tools.

## Competencies

- data quality;
- statistics;
- uncertainty;
- correlation vs causation;
- algorithmic limitations;
- interpretation.

## Principle

Data literacy strengthens human judgment; it does not replace it.
