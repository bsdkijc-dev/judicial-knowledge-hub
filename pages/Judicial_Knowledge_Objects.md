# Judicial Knowledge Objects

# Judicial Knowledge Object

Every significant Wiki page should be treated as a structured knowledge object.

## Minimum Metadata

- identifier;
- entity type;
- domain;
- jurisdiction;
- source;
- evidence level;
- status;
- AI readiness;
- verification state;
- relationships.
