# Transformation Maturity Model

# Transformation Maturity Model

Judicial transformation can be assessed through five maturity states.

1.  Initial — fragmented capability
2.  Digitising — processes become digital
3.  Integrated — systems and data become connected
4.  Intelligent — analytics and AI support institutional work
5.  Trusted — technology, governance and human capability produce

`  sustainable public value`

## Target

The long-term objective is a **Trusted Intelligent Judiciary**.
