# AI Readiness

**AI Readiness** describes how suitable a knowledge object is for reliable machine retrieval and AI-assisted processing.

## Proposed Scale

| Level | Description                           |
|-------|---------------------------------------|
| 0     | Unstructured                          |
| 1     | Basic text                            |
| 2     | Metadata available                    |
| 3     | Sources/citations structured          |
| 4     | Entities and relationships structured |
| 5     | Fully machine-readable and governed   |

## Readiness Factors

Assessment may consider:

- Stable identifier
- Clear title
- Entity type
- Domain
- Structured metadata
- Sources
- Citations
- Relationships
- Version
- Verification status

## AI Readiness ≠ Accuracy

A beautifully structured page can still contain incorrect information.

Therefore:

**STRUCTURE + EVIDENCE**

is preferable to structure alone.

## Target

High-value pages should progressively move toward:

**AI READINESS 4–5**
