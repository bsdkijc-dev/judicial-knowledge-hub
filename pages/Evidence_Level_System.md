# Evidence Level System

# Evidence Level System

## Levels

- E1 — Official primary source
- E2 — Verified institutional/research source
- E3 — Credible secondary source
- E4 — Analytical inference
- E5 — Hypothesis/proposal

## Rule

Evidence level must never be silently upgraded.
