# IJC:IJC-TRL-006

# Korelasi Multi-Artefak Phishing-to-Account Takeover

| Mode             | MODE 2 — TRIAL KNOWLEDGE            |
| Chamber / Domain | PIDANA / Pidana Khusus / Cybercrime |

## Definition

Pengambilalihan kendali akun melalui pencurian session cookie atau relay OTP tanpa modifikasi password akun asal (Bab 3).

## Established

Sesi web login baru aktif dari IP eksternal 4 menit setelah tautan phishing dibuka korban.

## Supported inference

Pencurian session cookie melewati proteksi MFA.

## Unknown / not established

Identitas fisik individu pengendali IP exit proxy.

## Atomic claims

- **IJC-CLM-0009** (FACT, NEEDS REVIEW): Tangkapan layar WhatsApp tidak menjamin keutuhan riwayat obrolan tanpa database msgstore.db native.
  - IJC-EVD-008 \[COPY, NEEDS REVIEW\]: Tangkapan Layar Pesan Chat WhatsApp Instruksi Transfer (PNG)
