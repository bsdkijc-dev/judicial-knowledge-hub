# Initiative Target

# Initiative Target

The target specifies the expected measurable improvement.

## Target Formula

**Baseline + Intervention = Target**

## Target Requirements

- measurable;
- time-bound;
- realistic;
- evidence-informed;
- connected to the initiative objective.

## Rule

Technology deployment itself is not a sufficient target.
