# Case Duration Analytics

Case Duration Analytics examines patterns in case processing time.

## Uses

- identify bottlenecks;
- compare workflows;
- support capacity planning;
- identify unusual delays.

## Boundary

Analytics should identify patterns for review rather than dictate judicial decisions.
