# Provenance Standard

# Provenance Standard

Every important judicial knowledge object should preserve its provenance.

## Provenance Elements

- original source;
- extraction date;
- transformation;
- editor;
- reviewer;
- publication date;
- version;
- supersession history.

## Knowledge Graph Requirement

Relationships should preserve source and temporal validity.
