# Judicial Technology Maturity Model

# Judicial Technology Maturity Model

Technology maturity should be assessed independently from the number of applications deployed.

| Level | Description          |
|-------|----------------------|
| 1     | Fragmented           |
| 2     | Digitised            |
| 3     | Integrated           |
| 4     | Intelligent          |
| 5     | Trusted and adaptive |

## Rule

Technology maturity should be evaluated alongside legal, process, data and human capability.
