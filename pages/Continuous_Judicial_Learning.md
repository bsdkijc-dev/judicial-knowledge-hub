# Continuous Judicial Learning

# Continuous Judicial Learning

Continuous Judicial Learning replaces a purely course-based model with lifelong capability development.

## Learning Components

- courses;
- communities of practice;
- simulations;
- post-deployment learning;
- competency assessment;
- continuous updating.

## Principle

**Learn → Apply → Evaluate → Update**
