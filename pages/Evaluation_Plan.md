# Evaluation Plan

# Evaluation Plan

Every major initiative should specify how success will be evaluated before deployment.

## Evaluation Components

- baseline;
- intervention;
- indicators;
- target;
- measurement method;
- evaluation period;
- responsible evaluator;
- decision rule.

## Core Principle

Evaluation should be designed before implementation rather than retroactively after deployment.
