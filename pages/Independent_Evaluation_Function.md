# Independent Evaluation Function

# Independent Evaluation Function

Major transformation programmes should be subject to independent evaluation.

## Functions

- validate baselines;
- assess outcomes;
- evaluate risks;
- test assumptions;
- review cost-effectiveness;
- recommend scale or termination.

## Principle

Implementation ownership and evaluation independence should be appropriately separated.
