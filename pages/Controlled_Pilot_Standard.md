# Controlled Pilot Standard

# Controlled Pilot Standard

Strategic technology initiatives should normally be tested in a controlled environment before national scale.

## Pilot Requirements

- defined scope;
- participating unit;
- baseline;
- risk tier;
- measurable outcome;
- data boundary;
- legal authority;
- cybersecurity controls;
- user training;
- evaluation plan;
- exit criterion.

## Decision

**Pilot → Evaluate → Scale / Redesign / Stop**
