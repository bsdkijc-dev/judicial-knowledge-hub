# Judicial Prompts Literacy

# Judicial Prompt Literacy

Judicial Prompt Literacy is the ability to formulate, evaluate and critically review AI instructions and outputs.

## Competencies

- task definition;
- source constraints;
- context management;
- verification;
- hallucination detection;
- privacy awareness.
