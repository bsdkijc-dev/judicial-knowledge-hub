# Institutional Memory Platform

# Institutional Memory Platform

The Institutional Memory Platform is proposed to preserve organisational knowledge across personnel changes and generations.

## Knowledge Sources

- institutional procedures;
- research;
- training;
- lessons learned;
- validated practices;
- historical knowledge.

## Strategic Outcome

Institutional knowledge should remain available even when experienced judges and staff retire or move.
