# AI Competency Framework

The framework defines role-specific competencies required for responsible judicial AI use.

## Competency Domains

- AI literacy;
- prompt literacy;
- data literacy;
- legal-tech literacy;
- verification;
- ethics;
- cybersecurity;
- governance.
