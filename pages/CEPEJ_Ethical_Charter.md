# CEPEJ Ethical Charter

# CEPEJ Ethical Charter

The CEPEJ Ethical Charter provides an international reference for responsible AI use in judicial systems.

## Core Principles

- fundamental rights;
- non-discrimination;
- quality;
- security;
- transparency;
- user control.

## Indonesian Relevance

The Charter can inform development of an Indonesian Judicial AI governance framework.
