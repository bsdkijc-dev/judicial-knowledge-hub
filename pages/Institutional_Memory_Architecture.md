# Institutional Memory Architecture

# Institutional Memory Architecture

Institutional memory preserves knowledge beyond individual personnel and administrative cycles.

## Knowledge Types

- decisions;
- policies;
- procedures;
- lessons learned;
- research;
- institutional history;
- innovation results;
- training materials.

## Objective

Knowledge should remain discoverable, reusable and machine-readable.
