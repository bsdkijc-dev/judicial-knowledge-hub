# Wiki Access Classification

# Wiki Access Classification

Knowledge should be classified according to sensitivity.

## Suggested Classes

- Public
- Internal
- Restricted
- Confidential
- Highly Sensitive

## Principle

The Wiki should never become a repository for material whose confidentiality requirements exceed its technical controls.
