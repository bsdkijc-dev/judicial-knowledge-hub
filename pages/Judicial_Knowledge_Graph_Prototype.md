# Judicial Knowledge Graph Prototype

# Judicial Knowledge Graph Prototype

The prototype should demonstrate how Wiki knowledge objects can become machine-readable relationships.

## Example

Case A → applies → Regulation B

Judgment C → interprets → Regulation B

Doctrine D → concerns → Legal Issue E

Initiative F → supports → Strategic Objective G

## Prototype Objective

Demonstrate semantic retrieval before attempting national-scale knowledge infrastructure.
