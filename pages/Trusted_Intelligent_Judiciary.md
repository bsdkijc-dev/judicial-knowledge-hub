# Trusted Intelligent Judiciary

The 2045 target is not an automated court.

It is a judiciary in which human judgment is strengthened by institutional knowledge, trusted data and responsible AI.

## Target State

- capable people;
- human judicial decision-making;
- accessible courts;
- connected knowledge;
- controlled AI;
- trusted data;
- proactive integrity;
- understandable justice;
- judicial ownership;
- independent evaluation.
