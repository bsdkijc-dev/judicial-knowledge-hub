# Category Governance

Categories are controlled vocabulary, not free-form tags.

## Rules

1.  Prefer existing categories.
2.  Avoid duplicate synonyms.
3.  Use singular entity categories where appropriate.
4.  Create a new category only when it represents a stable knowledge class.
5.  Review category proliferation periodically.
6.  Every strategic page should have at least one domain category.
