# Judicial Statistics API

# Judicial Statistics API

The Judicial Statistics API is proposed to provide documented, machine-readable access to approved judicial statistics.

## Requirements

- documented data definitions;
- stable interfaces;
- access controls where required;
- provenance;
- data-quality standards;
- cybersecurity.

## Strategic Function

An API can enable researchers, policymakers and authorised systems to use judicial statistics consistently.
