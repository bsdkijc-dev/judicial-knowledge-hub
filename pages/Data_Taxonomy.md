# Data Taxonomy

# Judicial Data Taxonomy

A common taxonomy is required to organise judicial data consistently.

## Candidate Classes

- Case Data
- Judgment Data
- Legal Data
- Court Data
- Personnel Data
- Performance Data
- Training Data
- Financial Data
- Public-Service Data
- Research Data

## Governance Attributes

Each data class should have:

- owner;
- source;
- sensitivity;
- retention;
- access level;
- quality standard;
- permitted uses.
