# Initiative Owner

# Initiative Owner

Every strategic initiative should have an accountable institutional owner.

## Owner Responsibilities

- define the problem;
- establish the baseline;
- coordinate dependencies;
- manage implementation;
- monitor risks;
- report outcomes;
- initiate evaluation;
- recommend scale, redesign or termination.

## Principle

**Every initiative needs an accountable owner.**
