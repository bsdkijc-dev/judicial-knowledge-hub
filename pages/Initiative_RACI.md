# Initiative RACI

# Initiative RACI

RACI defines institutional responsibility for an initiative.

| Role | Meaning     |
|------|-------------|
| R    | Responsible |
| A    | Accountable |
| C    | Consulted   |
| I    | Informed    |

## Rule

Every initiative should have one clearly identifiable accountable institutional owner.
