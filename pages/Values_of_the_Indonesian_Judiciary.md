# Values of the Indonesian Judiciary

# Values of the Indonesian Judiciary

The Blueprint identifies institutional values as the foundation of behavior and organizational culture.

## Strategic Function

Values provide a framework for:

- institutional behavior;
- professional conduct;
- organizational culture;
- public confidence.

## Verification Rule

The values stated in the 2010 Blueprint must not automatically be equated with later formulations of judicial ethical codes.

Such equivalence requires independent verification.
