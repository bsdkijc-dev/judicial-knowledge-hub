# Initiative Lessons Learned

Every major initiative should produce reusable institutional knowledge.

## Record

- original hypothesis;
- implementation experience;
- unexpected effects;
- successful practices;
- failures;
- risks discovered;
- user feedback;
- recommendations.

## Principle

**Failure is evidence when properly documented.**
