# Knowledge Graph Relationship Standard

# Knowledge Graph Relationship Standard

The Judicial Knowledge Graph should represent explicit relationships between judicial entities.

## Examples

- Case → concerns → Legal Issue
- Judgment → interprets → Regulation
- Regulation → contains → Article
- Court → handles → Case
- Initiative → supports → Strategic Objective
- Person/Role → responsible for → Initiative

## Requirements

Relationships should preserve:

- source;
- temporal validity;
- confidence;
- status.
