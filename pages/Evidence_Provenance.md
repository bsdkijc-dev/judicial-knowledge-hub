# Evidence Provenance

# Evidence Provenance

Evidence provenance records where a knowledge claim originated and how it can be verified.

## Provenance Fields

- Source title
- Author / institution
- Publication date
- Document version
- Page or section
- URL or repository
- Extraction date
- Verification status

## Principle

**No provenance → no high-confidence institutional knowledge.**
