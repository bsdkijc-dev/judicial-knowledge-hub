# Indicator Dictionary

# Strategic Indicator Dictionary

Lampiran IV provides the dictionary of strategic targets and indicators.

For each indicator, the matrix provides:

- strategic target;
- indicator name;
- indicator definition;
- calculation formula;
- unit of measurement.

## Knowledge-Wiki Function

The indicator dictionary should be treated as a core machine-readable knowledge layer.

**Indicator → Definition → Formula → Unit → Target → Evidence**

This structure should be preserved when importing the Renstra into the Judicial Knowledge Wiki.
