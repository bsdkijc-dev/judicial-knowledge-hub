# Initiative Dependencies

# Initiative Dependencies

Initiatives should explicitly identify capabilities or decisions that must exist before implementation.

## Dependency Types

- legal;
- organizational;
- data;
- technology;
- workforce;
- budget;
- procurement;
- interoperability.

## Dependency Logic

**Dependency → Prerequisite → Initiative**
