# Data Literacy

# Data Literacy

**Data literacy** is the ability to understand, interpret, evaluate, use, and communicate information derived from data.

## Core Skills

Data literacy may include:

- Data interpretation
- Basic statistics
- Data quality assessment
- Understanding datasets
- Identifying bias
- Understanding uncertainty
- Reading charts
- Understanding indicators

## Judicial Context

Judicial professionals may encounter:

- Case statistics
- Workload data
- Performance indicators
- Survey data
- Administrative datasets
- Research datasets

## Common Errors

Users should be cautious about:

- Correlation vs causation
- Small samples
- Selection bias
- Missing data
- Changing definitions
- Misleading averages
- Denominator errors

## AI Connection

AI output quality can depend heavily on:

**DATA QUALITY**
