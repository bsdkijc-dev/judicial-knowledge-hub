# Judicial AI Governance Framework

# Judicial AI Governance Framework

The Judicial AI Governance Framework establishes the institutional controls required for responsible use of artificial intelligence throughout the judicial lifecycle.

## Governance Scope

- purpose and legality;
- fundamental rights;
- data governance;
- security;
- risk management;
- human oversight;
- transparency;
- auditability;
- procurement;
- accountability.

## Lifecycle

**Design → Assess → Procure → Test → Deploy → Monitor → Audit → Review → Retire**

## Core Rule

**AI recommends. Human verifies. Judge decides.**
