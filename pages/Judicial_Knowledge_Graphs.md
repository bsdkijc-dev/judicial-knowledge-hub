# Judicial Knowledge Graphs

# Judicial Knowledge Graph

The Judicial Knowledge Graph represents judicial knowledge as interconnected entities and relationships.

## Graph Model

**ENTITY**

→ **RELATIONSHIP**

→ **ENTITY**

## Example

[Court](https://judicialknowledge.miraheze.org/wiki/Court) → applies → [Regulation](Regulation.md)

[Regulation](Regulation.md) → governs → [Procedure](https://judicialknowledge.miraheze.org/wiki/Procedure)

[Procedure](https://judicialknowledge.miraheze.org/wiki/Procedure) → generates → [Case Record](https://judicialknowledge.miraheze.org/wiki/Case_Record)

[Case Record](https://judicialknowledge.miraheze.org/wiki/Case_Record) → contributes-to → [Judicial Data](https://judicialknowledge.miraheze.org/wiki/Judicial_Data)

[Judicial Data](https://judicialknowledge.miraheze.org/wiki/Judicial_Data) → supports → [Judicial Research](Judicial_Research.md)
