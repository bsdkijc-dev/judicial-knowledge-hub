# Judicial Knowledge as Institutional Memory

# Judicial Knowledge as Institutional Memory

The future judiciary should transform institutional knowledge from fragmented documents into structured, connected and reusable knowledge.

## Target Architecture

- judgments;
- regulations;
- legal doctrine;
- policies;
- institutional practices;
- training materials;
- research;
- performance data;

should be connected through a common knowledge architecture.

## Judicial Knowledge Wiki

The [Judicial Knowledge Wiki](Judicial_Knowledge_Wiki.md) is proposed as one component of this institutional-memory architecture.

## Knowledge Graph

The Wiki should progressively connect knowledge objects through machine-readable relationships.

**Document → Knowledge Object → Entity → Relationship → Evidence**
