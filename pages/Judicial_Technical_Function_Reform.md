# Judicial Technical Function Reform

The Blueprint seeks to strengthen the technical judicial function so that judicial power is exercised independently, effectively, and fairly.

## Strategic Concerns

- quality of adjudication;
- consistency;
- judicial independence;
- judicial processes;
- case management.
