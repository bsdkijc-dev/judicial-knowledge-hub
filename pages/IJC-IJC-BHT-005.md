# IJC:IJC-BHT-005

# Standar Pemisahan Raw Evidence dan Derived Evidence dalam Forensik

| ID               | IJC-BHT-005                                      |
|------------------|--------------------------------------------------|
| Mode             | MODE 1 — BHT KNOWLEDGE                           |
| Chamber / Domain | PIDANA / Pidana Khusus / Forensik Digital        |
| Reference        | Putusan No. CONTOH-04/Pid.B/2026/PN.CONTOH (BHT) |
| Confidentiality  | PUBLIC                                           |
| Review status    | PASS                                             |
| Verified         | Cecep Mustafa, 2026-09-18 00:00:00               |

## Definition

Prinsip pemisahan permanen antara bukti asli (raw) dan hasil olahan (normalized, transkrip, enhancement, AI-analyzed) untuk auditability.

## Established

File raw forensic image disimpan read-only dengan SHA-256 baseline terverifikasi.

## Supported inference

Hasil transkrip AI speech-to-text dapat diaudit ulang ke rekaman audio sumber.

## Unknown / not established

Kebenaran narasi transkrip jika rekaman sumber mengalami kerusakan sektor.

## Atomic claims

- **IJC-CLM-0008** (PROCEDURAL_RULE, PASS): Hasil transkripsi otomatis AI merupakan derived evidence yang wajib dapat dilacak ke rekaman audio raw.
  - IJC-EVD-007 \[TRANSCRIPT, PASS\]: Transkrip Percakapan Telepon Modus Vishing Berbantuan AI

## Related questions

- IJC-Q-0006: Mengapa data olahan (derived evidence) seperti transkrip AI wajib dipisahkan dari bukti mentah (raw evidence)?
- IJC-Q-0008: Kapan investigator siber wajib menerapkan Professional Stopping Rule?
