# AI Readiness Framework

AI readiness measures whether a knowledge object can safely and reliably be used by AI systems.

## Levels

| Level | Description                      |
|-------|----------------------------------|
| 0     | Unstructured / unusable          |
| 1     | Digitized                        |
| 2     | Searchable                       |
| 3     | Structured                       |
| 4     | Linked and provenance-aware      |
| 5     | AI-ready and machine-retrievable |

## Minimum Requirements

AI-ready knowledge should have:

- identifiable source;
- structured content;
- stable metadata;
- provenance;
- relationships;
- verification status.
