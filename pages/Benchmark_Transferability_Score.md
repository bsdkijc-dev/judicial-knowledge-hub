# Benchmark Transferability Score

# Benchmark Transferability Score

International practices should receive a structured transferability assessment.

| Dimension                   | Score |
|-----------------------------|-------|
| Legal compatibility         | 1–5   |
| Institutional compatibility | 1–5   |
| Technology readiness        | 1–5   |
| Workforce readiness         | 1–5   |
| Financial feasibility       | 1–5   |
| Scalability                 | 1–5   |
| Rights compatibility        | 1–5   |
| Expected justice impact     | 1–5   |

## Principle

A high international reputation does not automatically imply high Indonesian transferability.
