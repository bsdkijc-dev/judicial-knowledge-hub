# Wiki–Repository Architecture

# Wiki–Repository Architecture

The Wiki should function as a knowledge layer rather than necessarily being the primary document-storage system.

## Architecture

**Source Repository → Curated Knowledge → Wiki → Knowledge Graph → AI / Search / Learning**

## Principle

Separate authoritative source storage from derivative knowledge representation.
