# Temporal Validity

# Temporal Validity

Judicial knowledge must account for changes over time.

## Relevant Events

- enactment;
- amendment;
- repeal;
- replacement;
- judicial interpretation;
- supersession.

## Critical Rule

A historical legal rule must not be presented as current merely because it appears frequently in a corpus.

## Wiki Implementation

Knowledge objects should include:

- effective date;
- end date where applicable;
- current status;
- superseded-by relationship.
