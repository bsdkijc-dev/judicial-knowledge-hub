# Knowledge Object

# Knowledge Object

A **Knowledge Object** is a structured unit of information managed by the Judicial Knowledge Wiki.

## Core Components

A knowledge object may contain:

- Stable ID
- Title
- Entity type
- Domain
- Definition
- Claims
- Sources
- Evidence level
- Relationships
- Version
- Status
- AI readiness
- Verification information

## Object Model

**IDENTITY** + **CONTENT** + **EVIDENCE** + **RELATIONSHIPS** + **PROVENANCE**

## Example

A court decision knowledge object might contain:

**ID** → CASE-0001

**TYPE** → Judicial Decision

**SOURCE** → Official decision

**CLAIM** → Legal proposition

**RELATIONSHIP** → interprets → Law X

## Benefits

Knowledge objects enable:

- Modular knowledge management
- Reuse
- Cross-linking
- Automated processing
- AI retrieval
- Version control

## Lifecycle

**CREATE** → **VERIFY** → **PUBLISH** → **UPDATE** → **ARCHIVE**
