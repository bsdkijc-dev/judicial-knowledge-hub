# Initiative Baseline

# Initiative Baseline

The baseline establishes the starting condition against which transformation is measured.

## Baseline Dimensions

- performance;
- cost;
- time;
- quality;
- access;
- workforce capability;
- technology maturity;
- user experience.

## Rule

No credible target should be established without a defensible baseline.
