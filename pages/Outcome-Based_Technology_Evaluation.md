# Outcome-Based Technology Evaluation

# Outcome-Based Technology Evaluation

A technology initiative should not be considered successful merely because the system has been launched.

Success must be demonstrated through measurable improvement in one or more of:

- justice quality;
- accessibility;
- timeliness;
- integrity;
- user experience;
- workforce capability;
- institutional resilience.

## Rule

**Deployment ≠ Success**

**Measured Outcome = Success Evidence**
