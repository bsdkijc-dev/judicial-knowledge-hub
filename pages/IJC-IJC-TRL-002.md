# IJC:IJC-TRL-002

# Pemeriksaan Modus Voice Cloning & Impersonasi Transfer Dana

| ID               | IJC-TRL-002                                          |
|------------------|------------------------------------------------------|
| Mode             | MODE 2 — TRIAL KNOWLEDGE                             |
| Chamber / Domain | PIDANA / Pidana Khusus / Cybercrime                  |
| Reference        | Perkara No. CONTOH-02/Pid.Sus/2026 (Sedang Berjalan) |
| Confidentiality  | RESTRICTED                                           |
| Review status    | NEEDS REVIEW                                         |
| Verified         | Cecep Mustafa, 2026-09-18 00:00:00                   |

## Definition

Sintesis suara tiruan menggunakan model generatif untuk memanipulasi kepercayaan otoritas finansial (Bab 2 & 6).

## Established

Panggilan suara masuk tercatat pada Call Detail Record & transfer dana Rp480jt terjadi.

## Supported inference

Representasi suara mengarahkan staf melakukan pemindahan dana darurat.

## Unknown / not established

Identitas operator sistem sintesis suara dan penguasaan rekening mule.

## Atomic claims

- **IJC-CLM-0003** (JUDICIAL_FINDING, NEEDS REVIEW): Instruksi transfer dana via telepon menggunakan representasi suara yang meniru direktur perusahaan.
  - IJC-EVD-003 \[RAW, PASS\]: Audio Recording Panggilan Masuk Suara Direktur (WAV native)
- **IJC-CLM-0004** (FACT, PASS): Panggilan vishing berasal dari nomor yang menggunakan teknik caller ID spoofing.
  - IJC-EVD-004 \[VERIFIED, PASS\]: Call Detail Record (CDR) Operator Seluler Telekomunikasi

## Related questions

- IJC-Q-0002: Apakah rekaman audio suara mirip direktur cukup untuk membuktikan tindak pidana vishing tanpa koroborasi?
