# Algorithmic Impact Assessment

Every high-impact judicial AI system should undergo an impact assessment before deployment and periodically thereafter.

## Assessment

- purpose;
- affected persons;
- legal basis;
- data sources;
- model limitations;
- error modes;
- potential harms;
- discrimination risks;
- cybersecurity risks;
- human oversight;
- fallback procedures;
- monitoring indicators.

## Review Trigger

The assessment should be revisited after significant changes to models, data, prompts, retrieval sources or vendors.

## Output

The assessment must produce an evidence record suitable for governance and audit review.
