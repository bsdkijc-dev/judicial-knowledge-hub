# Human Verification Queues

# Human Verification Queue

Claims requiring human verification should be explicitly tracked.

## Triggers

- missing source;
- ambiguous legal authority;
- outdated source;
- AI-generated claim;
- conflicting sources;
- high-impact interpretation.

## Workflow

**Flag → Review → Verify → Correct → Publish**
