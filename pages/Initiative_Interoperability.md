# Initiative Interoperability

# Initiative Interoperability

Digital initiatives should be assessed for interoperability before procurement and deployment.

## Dimensions

- data;
- identity;
- applications;
- APIs;
- metadata;
- security;
- workflow.

## Principle

A successful individual system can still be an institutional failure if it creates a new information silo.
