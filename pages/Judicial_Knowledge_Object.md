# Judicial Knowledge Object

A **Judicial Knowledge Object** is a discrete unit of structured knowledge concerning the judicial system.

## Required Metadata

| Field           | Description                          |
|-----------------|--------------------------------------|
| ID              | Unique knowledge identifier          |
| Entity Type     | Classification of the object         |
| Domain          | Knowledge domain                     |
| Jurisdiction    | Applicable jurisdiction              |
| Claim           | Substantive proposition              |
| Evidence        | Supporting source                    |
| Source Location | Page, paragraph, article, or section |
| Status          | Verification status                  |
| Relationships   | Links to other knowledge objects     |

## Principle

Every important knowledge claim should be traceable to evidence.
