Prompt Literacy

Prompt literacy is the ability to formulate effective, safe, precise, and verifiable instructions for an AI system.

Prompt Components

A useful prompt can specify:

  • Role
  • Objective
  • Context
  • Source
  • Constraints
  • Output format
  • Verification requirements

Weak Prompt

Explain this case.

Structured Prompt

Using only the supplied judicial decision:

1. Identify the legal issues.
2. Extract the relevant rules.
3. Summarize the reasoning.
4. Identify the holding.
5. Cite the exact source location.
6. Flag anything that cannot be verified.

Safety

Users should avoid entering confidential or protected information unless authorized by applicable institutional rules and technical controls.

Verification

A good prompt should explicitly tell the AI:

DO NOT INVENT SOURCES.
