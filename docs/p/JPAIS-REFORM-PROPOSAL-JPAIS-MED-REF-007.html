JPAIS:REFORM-PROPOSAL:JPAIS-MED-REF-007

By Cecep Mustafa, Indonesian Judicial College (IJC) · revision 971, 2026-09-15 · wiki source · Markdown

Summary / Ringkasan

Entity Ingestion / Ingesti Entitas

  • Entity ID: JPAIS-MED-REF-007
  • Knowledge Grapher: Cecep Mustafa
  • Ingestion Status: Confirmed

Description / Deskripsi

Provides an exhaustive comparative assessment of digital court case management systems between Indonesia and Japan, examining technical topologies, e-filing onboarding, interoperability middleware (Puskarda/SPPT-TI vs. Japanese centralized platforms), cybersecurity governance, and proposing the cloud-native e-Peradilan Modern reference architecture and a 90-day pilot execution plan[cite: 7].

Problem / Masalah

  • JPAIS-MED-PROB-001: Indonesia's decentralized SIPP database topology suffers from asynchronous synchronization failures, packet loss in remote islands, concurrency conflicts, and manual EIS metric manipulation risks[cite: 7].
  • JPAIS-MED-PROB-002: Inter-agency criminal integration (SPPT-TI) experiences semantic divergence and identifier misalignments due to the lack of an immutable Master Person Index anchored to national identity numbers (NIK)[cite: 7].
  • JPAIS-MED-PROB-003: Court records are stored as unstructured binary PDF/DOCX files without machine-readable legal ontologies (LegalDocML), while decentralized servers expose vulnerabilities to web defacements and unmonitored scraping[cite: 7].

Current Indonesian Practice / Praktik Indonesia Saat Ini

  • JPAIS-MED-ID-001: Decentralized IT infrastructure utilizing local SIPP database nodes across 800+ working units, synchronized upstream daily to central servers, combined with e-Court and e-Berpadu portals under Supreme Court regulations[cite: 7].

Japanese Practice / Praktik Jepang

  • JPAIS-MED-JP-001: Centralized cloud and server repository managed by the Supreme Court, operating under statutory amendments (Act No. 48 of 2022) with the "3e" framework (e-Court, e-Filing via mints, e-Case Management)[cite: 7].

Gap / Kesenjangan

  • JPAIS-MED-GAP-001: Reliance on autonomous judicial decrees (PERMA) rather than primary parliamentary legislation, creating legal friction, alongside asynchronous synchronization vulnerabilities and unstructured file storage[cite: 7].
  • JPAIS-MED-GAP-002: Absence of machine-readable legal schemas (Akoma Ntoso), unautomated personal identifiable information (PII) redaction exposing PDP law compliance risks, and digital divide barriers for pro-se litigants[cite: 7].

Proposed Adaptation / Adaptasi Usulan

Adopt the e-Peradilan Modern reference architecture: replace decentralized SIPP instances with a multi-tenant PostgreSQL cloud backbone, upgrade Puskarda into an Apache Kafka event mesh with an MPI Master Person Index, adopt OASIS LegalDocML (Akoma Ntoso) XML schemas, enforce BSrE hardware security module digital signatures, and institute automated PII redaction[cite: 7].

Action / Aksi

  • JPAIS-MED-ACT-001: Form multi-agency PMO (Supreme Court, BSSN, Komdigi, Polri, Kejaksaan), enact Supreme Court Pilot Decree, publish canonical LegalDocML schemas, and provision staging cloud environments[cite: 7].
  • JPAIS-MED-ACT-002: Deploy BPMN 2.0 workflow engine, integrate SIPP change-data-capture connectors, install PTSP self-service pro-se kiosks, and connect Puskarda 2.0 to local law enforcement registries[cite: 7].
  • JPAIS-MED-ACT-003: Cut over pilot court civil and criminal dockets to e-Peradilan Modern, conduct MA-CSIRT/BSSN penetration testing, audit PII redaction accuracy, and deliver national scaling report[cite: 7].

Pilot / Pilot Proyek

  • JPAIS-MED-PILOT-007: 90-day multi-agency pilot program across Central Jakarta District Court (PN Jakarta Pusat) and Surabaya District Court (PN Surabaya)[cite: 7].

KPI / Indikator Kinerja Utama

  • JPAIS-MED-KPI-007: Synchronization latency $< 5$ seconds; inter-agency handshake velocity $< 120$ minutes; LegalDocML parsing rate $\ge 95\$; PDP PII redaction precision/recall $\ge 99.2\$; pro-se completion $\ge 80\$; zero unauthorized database modifications; instant appellate bundle compilation ($< 10$ minutes)[cite: 7].

Policy Implication / Implikasi Kebijakan

Establish high-level inter-agency steering committees and PMO oversight to govern master data management, cybersecurity telemetry, and legal-tech standardization[cite: 7].

Regulatory Implication / Implikasi Regulasi

Codify electronic procedures directly within the forthcoming national Civil Procedure Code and promulgate joint ministerial data-sharing protocols under SPPT-TI[cite: 7].

Evidence / Bukti Empiris

  • Indonesia's e-Court registered 410,754 first-instance cases in 2024 and mandated electronic appellate transmission, but struggles with synchronization bottlenecks across 800+ local databases[cite: 7].
  • Japan's statutory-backed mints platform and centralized e-Case Management establish a unified, high-integrity cloud repository taking full statutory effect on May 21, 2026[cite: 7].
