AI Literacy

AI literacy is the ability to understand, use, evaluate, and critically assess artificial intelligence systems.

Core Knowledge

AI literacy may include understanding:

  • AI terminology
  • Machine learning
  • Generative AI
  • Large language models
  • Training data
  • Retrieval
  • Hallucination
  • Bias
  • Privacy
  • Security
  • Human oversight

Practical Skills

A literate user should be able to:

  • Select an appropriate AI tool
  • Formulate a useful task
  • Protect sensitive information
  • Evaluate outputs
  • Verify sources
  • Recognize uncertainty
  • Escalate high-risk use

Judicial Context

Judicial AI literacy should emphasize:

PROFESSIONAL JUDGMENT > AUTOMATION

AI should be understood as a tool whose outputs require contextual evaluation.

Minimum Competency

Users should know:

1. What AI can do. 2. What AI cannot reliably do. 3. What information should not be disclosed. 4. How to verify outputs. 5. When human expertise is mandatory.
