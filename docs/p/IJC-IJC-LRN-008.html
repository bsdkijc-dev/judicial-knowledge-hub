Pedoman Penghentian Investigasi (Professional Stopping Rule) & Privasi Data

ID IJC-LRN-008
Mode MODE 4 — JUDICIAL LEARNING
Chamber / Domain PIDANA / Etika Yudisial & Privasi Data
Reference Panduan Teknis Investigasi Siber 2026
Confidentiality PUBLIC
Review status PASS
Verified Cecep Mustafa, 2026-09-18 00:00:00

Definition

Kewajiban menghentikan eksploitasi data digital ketika target melampaui surat tugas, menemukan data anak, atau melanggar UU PDP No. 27/2022.

Established

Penyidik dilarang mencoba kredensial aktif yang ditemukan di forum terbuka tanpa otorisasi sah.

Supported inference

Pencegahan mission creep melindungi integritas pembuktian di sidang pengadilan.

Unknown / not established

Batas waktu retensi seragam untuk seluruh kategori bukti elektronik.

Atomic claims
