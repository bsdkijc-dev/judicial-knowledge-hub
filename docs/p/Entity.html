Entity

An entity is a uniquely identifiable object represented within the Judicial Knowledge Wiki.

Entity Examples

Entities may include:

  • Court
  • Judge
  • Case
  • Decision
  • Law
  • Regulation
  • Procedure
  • Right
  • Institution
  • Dataset
  • AI system
  • Research project

Entity Identity

Each important entity should ideally have:

  • Stable ID
  • Preferred name
  • Alternative names
  • Entity type
  • Jurisdiction
  • Date information
  • Source
  • Status

Entity vs Concept

An entity generally refers to an identifiable object.

A concept may represent an abstract idea.

For example:

Mahkamah Agung RI → institution/entity

Judicial Independence → concept

The distinction may depend on the knowledge model.

Entity Linking

Different pages referring to the same entity should preferably link to one canonical page.

AI Use

Explicit entity identification improves:

  • Retrieval
  • Disambiguation
  • Graph construction
  • Entity resolution
  • AI grounding
