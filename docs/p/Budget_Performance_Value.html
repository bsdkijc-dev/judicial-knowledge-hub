Budget Performance Value

Indicator 3.2 measures budget performance.

Composition

The value consists of:

  • 50% Budget Planning Performance Value;
  • 50% Budget Implementation Performance Value.

Budget Planning

Includes:

  • effectiveness;
  • achievement of strategic performance indicators;
  • effectiveness of Echelon I units;
  • effectiveness of work units;
  • efficiency.

Budget Implementation

Includes:

  • DIPA revisions;
  • budget absorption;
  • settlement of bills;
  • SPM dispensations;
  • DIPA page deviation;
  • contractual expenditure;
  • UP and TUP management;
  • output achievement.

The indicator measures performance for the preceding year (t−1).

Target

90 for each year, 2025–2029.
