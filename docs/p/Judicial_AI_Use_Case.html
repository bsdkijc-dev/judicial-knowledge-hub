Judicial AI Use Case

A Judicial AI Use Case describes a specific application of artificial intelligence within a judicial environment.

The purpose of this object is to distinguish concrete AI applications from general claims about AI.

Use Case Template

Field Description
Use Case ID Unique identifier
Problem Problem being addressed
User Intended user
AI Function What the AI performs
Input Data supplied to the system
Output Result generated
Human Role Human review or decision
Risk Potential harm
Safeguards Controls
Evidence Supporting documentation
Status Proposed / Pilot / Operational / Retired

Example Use Cases

Potential low-risk examples:

  • Document summarization
  • Transcription
  • Translation
  • Knowledge classification
  • Search assistance
  • Training material generation

Potentially higher-risk examples require separate assessment.

Risk Classification

Each use case should be assessed for:

  • Rights impact
  • Privacy impact
  • Accuracy requirements
  • Automation level
  • Human oversight
  • Data sensitivity

Evidence Requirement

A use case should not be described as operational merely because an institution has discussed it.

Evidence should distinguish:

PROPOSED

from

PILOT

from

DEPLOYED

from

EVALUATED
